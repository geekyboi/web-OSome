# Example plugins

These aren't loaded: TV Home only looks in `plugins/`. To try one, copy its folder into
`plugins/` (on the TV: `/media/developer/apps/usr/palm/applications/net.local.tvhome/plugins/`)
and it appears within about 30 seconds. Remove it again the same way.

- `hello`: "Hello, world!" in a glass card at the bottom of the right-hand column. The
  smallest useful tile: `plugin.json`, `tile.js` and `tile.css`, with comments.

How plugins work is in `plugins/README.md`.
